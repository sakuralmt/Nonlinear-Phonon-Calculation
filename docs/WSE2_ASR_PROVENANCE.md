## 为什么要区分后来的关键模式和耦合数据

后来的 `wse2_qe_raw_important_20260527/baseline_stage1/system.scf.inp` 使用 80/800 Ry；高耦合对的方向来自 `wse2_stage2_stage3_core_20260402/.../stage1/outputs/mode_pairs.selected.json`。该文件中使用的 Γ 第8支为 7.545686 THz，而上述早期全网格同编号支为 7.577818 THz，已经足以表明它们不是同一份模态导出。此处不把编号相同当作模式匹配的证明。

报告中的全网格频率表与高耦合系数表分别读取上述不同数据源。未施加 ASR 的 Γ 声学频率不能作为否定后一个表的依据；同样，也不能由已有关键模式复核推断早期全网格已做了统一 ASR。

## 影响范围与处理

1. Γ 的三个整体平移模式应在平移不变的力常数下为零；直接用未修正的 QE Γ 声学支给已修正的 MLFF 打分，会把后处理差异混入模型误差。因此现有主表只统计 35 个有限 q 点，并保留原始 Γ 数据以便追溯。
2. 这不表示有限 q 的 ASR 影响已被证明为零；完整力常数统一施加 ASR 后可能改变有限 q 频率。现有有限 q 表仍是带有后处理差异的历史参照，不能升级为严格统一的精度基准。
3. 正式筛选仅使用 Γ 光学模。上述 Γ 声学偏离不会直接进入候选或耦合排名；但统一 ASR 也可能改变光学模与本征矢，不能宣称对光学量影响严格为零。
4. 若要量化 ASR 对这份早期数据的影响，应另存对已有动力学矩阵/力常数的后处理结果，与原始导出逐模比较，不覆盖原档。后处理本身无需重跑电子结构或 DFPT；本次仅核查文件并更正报告，没有启动新计算。

QE 官方说明：[`dynmat.x`](https://www.quantum-espresso.org/Doc/INPUT_DYNMAT.html) 的 `asr='no'` 不施加求和规则，`crystal` 对 Γ 动力学矩阵施加三个平移约束；[`matdyn.x`](https://www.quantum-espresso.org/Doc/INPUT_MATDYN.html) 的 ASR 则在实空间力常数上处理。两种处理路径不可不加区分地混称为同一个已验证基准。
