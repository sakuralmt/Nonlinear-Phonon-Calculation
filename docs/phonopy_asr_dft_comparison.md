# Phonopy ASR 与归档 QE 声子的对照（2026-09-24）

本报告针对 6×6×1 谐波声子。MLFF 只使用两种材料的**共用 DFT 输入结构**；模型自行弛豫的结构没有混入 DFT 误差统计。模式以本征矢重叠做一对一匹配，0.1 THz 内的近简并支另按子空间比较。每个 q、每支频率、匹配和重叠见 `scripts/audit_asr_and_dft_phonons.py` 生成的完整 JSON；本轮不新增 DFT 电子结构或势能面计算。

## ASR 的实际处理

Phonopy 自带 ASR。测试工作树将 `phonopy==2.38.0` 固定，并对拟合出的**完整超胞力常数**显式调用 `symmetrize_force_constants(level=1)`；它施加平移求和规则和力常数的指标交换对称性。原始和修正的力常数、最大行漂移、最大修正量都单独保存。该操作不是空间群筛选，也不自动施加 2D 的转动求和规则。旧 Stage1 数据此前没有显式 ASR，故下表同时给出原始诊断与 Phonopy 修正后的结果。

| MLFF，共用结构 | 原始最大平移漂移 (eV/Å²) | Phonopy ASR 后 | 原始 Γ 声学频率范围 (THz) | 6×6 有限 q 最大频率变化 |
| --- | ---: | ---: | ---: | ---: |
| MoS₂ Prophet | 0.00454 | 3.82×10⁻¹⁴ | −0.01360…+0.00799 | 4.5×10⁻¹⁴ THz |
| MoS₂ EquiformerV3 | 0.00143 | 6.96×10⁻¹⁴ | −0.01062…+0.01126 | 5.5×10⁻¹⁴ THz |
| WSe₂ Prophet | 0.03559 | 9.50×10⁻¹⁴ | −0.00807…+0.00483 | 3.1×10⁻¹⁴ THz |
| WSe₂ EquiformerV3 | 0.00226 | 1.21×10⁻¹³ | −0.00790…+0.00876 | 8.4×10⁻¹⁴ THz |

ASR 后四者的 Γ 声学频率均在约 5×10⁻⁷ THz 内归零。上述 6×6 有限 q 点几乎不变，但**不能据此说 Γ 附近全部可靠**。在网格外 q=(1/12,0,0) 的插值检查中，ASR 后最低支仍为 MoS₂ Prophet −0.243 THz、EquiformerV3 −0.261 THz；WSe₂ Prophet −0.244 THz、EquiformerV3 −0.231 THz。两模型在共用结构上都有这个低 q 虚频现象；只做平移 ASR 不能解决可能的 ZA 转动不变性、有限超胞截断或结构应变问题，需要独立验证，不能把这些插值点当作已经验证的物理预测。

真正从模型力重新生成的 Phonopy + ASR MoS₂/EquiformerV3 CPU 首轮试跑为 Slurm `1019380`，58 秒，36 q 点、486 候选。该次原始漂移 6.83×10⁻⁵ eV/Å²，修正后 7.74×10⁻¹⁴ eV/Å²，最大力常数修正 7.73×10⁻⁴ eV/Å²。最终相位规则又在 `1019396` 中顺序跑完 MoS₂/WSe₂ 共用结构两条线：总用时 1 分 54 秒，各 486 对，原始/ASR 后漂移分别为 7.00×10⁻⁵ → 1.31×10⁻¹³ 和 1.23×10⁻⁴ → 4.98×10⁻¹⁴ eV/Å²。相对各自原有 EquiformerV3 网格，有限 q 频率最大差仅 0.000296/0.000163 THz；两套 Phonopy 参数归档重新载入后的力常数与 v3 保存值最大差均为 8.9×10⁻¹⁶ eV/Å²。

最终 Phonopy+ASR 重新计算的数据与归档 QE 对照后，MoS₂/WSe₂ 全网格频率 MAE 分别为 0.08215/0.10787 THz；有限 q 声学 MAE 为 0.07884/0.07783 THz，有限 q 光学 MAE 为 0.08329/0.11797 THz。孤立模本征矢重叠²中位数分别为 0.99916/0.99849。逐 q 原始结果与匹配记录分别保存在 `asr_dft_equiformer_phonopy_final.json`。这些数值仍受下述 QE 几何来源与 WSe₂ QE ASR 不一致的限制。

## 与 QE 的逐类频率和本征矢比较

下表使用**未经 ASR 的历史 MLFF 数据**，以便保留原始模型误差。频率误差单位 THz。ASR 后 MoS₂ 两模型全网格 MAE 分别变为 0.1645 和 0.0822；WSe₂ 分别变为 0.1625 和 0.1079。6×6 有限 q 指标在表格精度内不变。

| 材料、模型 | 全部 324 模 MAE | 有限 q 声学 105 模 MAE | 有限 q 光学 210 模 MAE | 孤立模本征矢重叠²中位数 | 近简并子空间重叠中位数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| MoS₂ Prophet | 0.1646 | 0.1113 | 0.1930 | 0.99880 | 1.00000 |
| MoS₂ EquiformerV3 | 0.0823 | 0.0789 | 0.0833 | 0.99916 | 0.99999 |
| WSe₂ Prophet | 0.1625 | 0.1630 | 0.1587 | 0.99601 | 0.99967 |
| WSe₂ EquiformerV3 | 0.1079 | 0.0778 | 0.1180 | 0.99849 | 0.99971 |

在当前归档 QE 数据下，EquiformerV3 的频率和多数孤立模本征矢比 Prophet 更接近 QE；这还不是非线性耦合的比较。MoS₂ 的 M=(1/2,0) 九支平均绝对误差为 Prophet 0.223、EquiformerV3 0.097 THz；K=(1/3,1/3) 为 0.209、0.082 THz。WSe₂ 的对应 M 为 0.196、0.130 THz，K 为 0.185、0.105 THz。MoS₂ 孤立模最低重叠²为 Prophet 0.9796、EquiformerV3 0.9894；WSe₂ 分别为 0.8966、0.9680。Γ 的近简并支只按子空间解读，不能用任意单支旋转来断言谁的模式更准确。

旧的 GPTFF/MatterSim 全网格比较仍可作为单独历史背景。在 MoS₂ 相同输入文件下，归档 MatterSim 的全模 MAE 为 0.349 THz、孤立模重叠²中位数 0.991；GPTFF-v1/v2 分别为 2.939/3.439 THz 和 0.913/0.932。WSe₂ 旧实验使用另一个结构哈希 `352f3bbd…`，其归档 MatterSim 为 0.288 THz、0.991，GPTFF-v1/v2 为 2.115/1.663 THz、0.933/0.948。**这些 WSe₂ 旧值不与上表的共用结构结果合并排名。**

## DFT 对照的证据边界

MoS₂ 归档 `matdyn` 使用 `asr='simple'`，QE Γ 声学频率为 0。WSe₂ 归档由 12×12 原始动力学矩阵取 6×6 子集，并以 `dynmat.x asr='no'` 对角化；QE Γ 三条声学频率为 −0.4416、+0.4940、+0.5181 THz。因此 WSe₂ **Γ 声学 MAE 不应作为 MLFF 准确度指标**；上表应优先看有限 q 声学/光学和 Γ 光学。两套 QE 后处理的 ASR 设置不同，也不宜把全模 MAE 当作严格统一基准。

更关键的是，归档 MoS₂ QE 的原始弛豫结构来源尚无独立证明；WSe₂ 12×12 原始 QE 与本轮输入结构的 Se 坐标相差约 0.000378 Å。转换后的 QE 数据集虽携带与 MLFF 输入一致的结构哈希，但 `qe_geometry_verified=false`，这是转换时指定的比较结构，**不是原始 QE 计算几何已核实的证据**。所以上述数值是有价值的历史诊断，不是正式的同结构误差宣称。完整 JSON 保留了 36 个 q 点的逐模频率、映射及子空间分数。

本轮没有已核实几何和模式映射的完整 DFT 势能面，因而还不能报告 3/4 阶耦合的 DFT MAE、RMSE 或 top-N 召回。**比较物理耦合不要求两份计算的实位移逐点重合**：先核对结构与单位，再通过有限 q 复模的相位/q↔−q 关系及简并子空间映射，比较 `|Φ₁₂₂|` 或子空间范数等不变量。若只有旧 QE 模式基的一条单支能量网格，却缺少简并子空间的其他方向或混合项，不能据此恢复完整的基底旋转；应标记为仅能做有限的描述性比较。只有逐点相减两个固定坐标的能量网格才需对齐实际位移。本轮 Stage3 按用户要求暂停，所有 Slurm 测试合计控制在 10 个节点以内。
