# TECE-OAM-RRA-1.0 CPU Stage1 验证（2026-09-24）

本轮把 TECE 作为 Prophet Stage1 的候选替代模型，在独立环境中锁定源码、权重与依赖。模型在 MoS₂、WSe₂ 的周期性三原子输入上通过重复能量/力、非零位移处的能量导数与原子力一致性检查；两种材料的导数偏差分别约为 1.28×10⁻⁴ 和 1.45×10⁻⁴ eV/Å。TECE 权重 SHA256 为 `9f36562582d931347c3904f763e820edcaf5f27c3f13beb6776e49fcc7de38bb`。这些是接口与保守力检查，不是声子精度结论。

在 16 CPU 核的 Slurm 节点上，MoS₂ 6×6×1 超胞含 108 个原子；TECE 单次能量/力推理在 4、8、16 个 PyTorch 线程下分别约为 5.3–5.7、2.5、1.8 秒，进程峰值 RSS 约 5.8 GB。模型参数量没有被用作排名优劣标准；这里测时仅用于决定能否按服务器资源运行完整 Stage1。

随后 CPU 作业 `1019418` 和 `1019423` 分别完成共用结构与 TECE 自行弛豫结构的 Phonopy 2.38＋ASR Stage1。每条线有 36 个 q 点、486 个 Γ–q–(−q) 候选；没有按声子分支或预测耦合删除候选。

TECE 自行弛豫使用与其他模型一致的受约束 QE 输入协议、固定真空方向，并以 TECE 自己的能量/力优化；MoS₂/WSe₂ 的最佳面内尺度相对共用输入分别为 1.01944/1.02351。优化结构和各次试探都由服务器上的 `relax_summary.json` 追溯。两条结构线不混排。

在相同共用输入结构上，TECE 与 Prophet Phonopy 的全网格匹配频率 MAE 为 MoS₂ 0.1513 THz、WSe₂ 0.1092 THz，孤立模本征矢重叠²中位数分别为 0.99881、0.99884。对归档 QE 的描述性比较，TECE 的全网格频率 MAE 为 MoS₂ 0.06596 THz、WSe₂ 0.12585 THz，孤立模重叠²中位数为 0.99958、0.99905。**归档 QE 原始几何尚未独立核实，WSe₂ 的旧 QE 数据又未施加 ASR；这些是历史诊断，不是严格的同结构 DFT 准确度宣称。**

TECE Stage1 到 MatterSim Stage2 的候选交接仍需按物理等价模式映射来做。生产流程应先排序筛选，再对入选通道做高精度复核；无需仅为比较模型尺寸而对所有 TECE 候选重复完整 MatterSim 网格。当前 DFT Stage3 按用户要求暂停。
